# Issue tracker

Repository issues are tracked on GitHub Issues at: https://github.com/nikolalazarevic011/jbs-store-remake

That repo is `origin` and is the canonical repo for this project. The `work` remote (`lwcc-web/JBS-store-theme`) is a secondary mirror and is **not** the issue-tracking surface.

Workflow summary
- Primary workflow: use GitHub Issues for tracking work and discussion.
- Recommended CLI: `gh` for creating and managing issues locally.
- PRs as a request surface: disabled by default, open PRs are not automatically treated as triage requests.

Usage notes
- Before any `gh` operation, confirm the active account. Never switch to the work account without asking.
- Never push to the `work` remote without explicit user consent.
